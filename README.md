# E-Commerce-Data-Warehouse-and-ETL-Pipeline
This is a Data Engineering Project of E-Commerce Data Warehouse and ETL Pipeline
This Project includes datasets of customers,order_items,orders,payments and products as csv files ie 
customers.csv,order_items.csv,payments.csv and products.csv.
The ETL Pipeline is constructed through data cleaning and duplicates removal in Python,Pyspark is used for dataframing operations,Star-Schema data warehouse design is also added based on the project datasets and business queries are answered through SQL Analytics.
